# Boot Camp Journal

This is where I document my journey  every single day, from the very first 
class, through a 6-month full-stack software development bootcamp at 
ITSkillsCenter, Lagos, Nigeria, starting August 2026.

## Why this exists

I don't just want to finish a bootcamp. I want to actually understand what 
I'm learning, deeply enough to explain it, question it, and build with it 
long after the class ends. So every day, after class, I come back here — I 
rebuild what I learned, dig into what confused me, and write it all down 
honestly. Not a polished summary. The real process — the struggle, the 
questions, the small wins.

Whatever I become from this point on, this journal is a big part of how I 
got there. It's the proof of every day I showed up, even the hard days.

## Format

Each entry in `journal.md` follows this structure:
- **Learned** — what was covered that day, explained in my own words
- **Struggled with** — what confused me, and how I worked through it
- **Tomorrow** — what's coming next
